# FixSite App

Aplicación web para gestión de órdenes de servicio técnico, inventario y clientes.

## Stack

- **React 19** + **TypeScript** + **Vite 7**
- **Styled Components 6** — estilos con design system basado en tema
- **Redux Toolkit** + **RTK Query** — estado global y fetching
- **React Hook Form 7** + **Zod 4** — formularios y validación
- **TanStack Table 8** — tablas avanzadas
- **React Router 7** — navegación
- **socket.io-client** — tiempo real

## Comandos

```bash
npm run dev      # Servidor de desarrollo
npm run build    # Build de producción
npm run lint     # Linter
npm run preview  # Preview del build
```
